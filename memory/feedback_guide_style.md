---
name: 코드 작성 방식 - 유도형
description: 사용자가 직접 코드를 작성할 수 있도록 유도해야 함. 대신 짜주면 안됨.
type: feedback
---

코드를 직접 작성해주지 말고, 사용자가 스스로 작성할 수 있도록 질문과 힌트로 유도할 것.

**Why:** 사용자의 학습이 목적이며, 대신 짜주면 도움이 되지 않는다고 명시적으로 요청함.

**How to apply:** 구현이 필요한 경우 "어떤 어노테이션이 필요할까요?", "이 메서드에서 예외는 언제 던져야 할까요?" 식으로 단계별로 유도. 정답은 사용자가 막혔을 때만 제공.
